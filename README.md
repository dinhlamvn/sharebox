# Local file transfers

ShareBox stores library content locally. Use the transfer icon in a box to export
an offline `.sharebox` package or explicitly upload it to Firebase. Use
**Transfer boxes** in the box list or settings to import a package or download
with a transfer code.

See [local transfer behavior, limits, and Firebase setup](docs/local-transfers.md).
